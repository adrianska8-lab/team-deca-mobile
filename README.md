# TEAM DECA — Consultoria Fitness (Mobile)

Versão mobile/tablet do planejador alimentar TEAM DECA — HTML/CSS/JS puro, sem build, sem dependências além de CDNs (Chart.js, pdf.js, Google Identity Services).

Aberto diretamente (`index.html`) funciona para tudo, exceto a integração com Google Agenda, que exige ser servido via `http://`/`https://` (veja instruções no app, aba **Alunos → Google Agenda**).

## Deploy (GitHub Pages)

Este repositório é publicado via GitHub Pages a partir da branch `main`, pasta raiz — `index.html` é servido diretamente na URL do Pages.
